## 2. 오늘의 핵심 세 줄

> **① 리스트 메서드는 원본을 직접 바꾼다 — 문자열과 반대!**
> `temps.sort()` 로 끝. `temps = temps.sort()` 는 `None`이 된다.

> **② 조건문·반복문 모두 콜론(:) + 들여쓰기가 블록을 만든다.**
> 들여쓰기 안 = 조건부/반복됨, 밖 = 항상/한 번.

> **③ 누적은 반복 밖에서 준비한다.**
> `total = 0`, `count = 0`, `results = []` 를 반복 **안**에 넣으면 매 바퀴 초기화되는 함정.

## 3. 치트시트 — 리스트 (04_01)

```python
temps = [25, 26, 24, 28, 27]    # 대괄호 + 쉼표
temps[0]     temps[-1]          # 인덱싱 (0부터 / 뒤에서)
temps[1:4]   temps[:3]          # 슬라이싱 (끝 제외)
temps[2] = 99                   # 그 자리만 교체
len(temps)                      # 개수
"모터" in machines               # 포함 여부
```

| 용도 | 메서드 |
|---|---|
| 추가 | `append(값)` 끝에 · `insert(위치,값)` 끼워넣기 · `extend(리스트)` 이어붙이기 |
| 제거 | `remove(값)` 값 기준 · `pop(위치)` 꺼내며 · `del t[위치]` 그냥 삭제 |
| 정렬 | `sort()` · `sort(reverse=True)` · `reverse()` 뒤집기 |
| 탐색 | `count(값)` 개수 · `index(값)` 처음 위치 |

정렬 후 `temps[0]`=최소, `temps[-1]`=최대.

## 4. 치트시트 — 조건문 (04_02)

```python
if score >= 90:        # 좁은(높은) 기준을 위에!
    print("A")
elif score >= 80:      # 앞이 거짓일 때만 검사
    print("B")
else:                  # 나머지 전부
    print("F")
```

- 이상 `>=` 포함 / 초과 `>` 미포함 — 경계에서 판정이 갈린다
- `20 <= temp <= 60` — 연쇄 비교 (`and` 없이 범위)
- 조건식엔 `==` (하나짜리 `=`는 대입 → `SyntaxError`)

## 5. 치트시트 — 반복문 (05_01 ~ 05_03)

### for + range

```python
range(5)          # 0 1 2 3 4     (끝 미포함!)
range(1, 6)       # 1 2 3 4 5
range(0, 10, 2)   # 0 2 4 6 8
range(5, 0, -1)   # 5 4 3 2 1    (역순)
range(1, n + 1)   # 1부터 N '포함'
```

### while — 안전 3점검

```python
count = 1                # ① 시작값
while count <= 3:        # ② 언젠가 거짓이 되는 조건
    print(count)
    count += 1           # ③ 거짓 방향으로 갱신  ← 빼먹으면 무한 루프 (Ctrl+C 탈출)
```

횟수를 알면 `for`, "조건을 만족할 때까지"면 `while`.

### break / continue

| | `break` | `continue` |
|---|---|---|
| 하는 일 | 반복 **전체** 종료 | **이번 회차**만 건너뜀 |
| 목적 | 찾았으니 그만 | 거르고 계속 |

`while True:` + `break` = 종료 시점을 반복 안에서 정하는 패턴.

### 데이터 처리 4대 패턴 (05_03)

```python
# ① 출력            # ② 필터링 출력       # ③ 누적 계산         # ④ 새 리스트
for t in temps:     for t in temps:      total = 0            hot = []
    print(t)            if t > 30:       for t in temps:      for t in temps:
                            print(t)         total += t           if t > 30:
                                                                      hot.append(t)
```

- 그릇(`total = 0`, `hot = []`)은 반복 **밖**에서 준비
- 부분 평균은 `total / count` — `len(전체)`로 나누면 틀림!
- 최댓값: `biggest = temps[0]`에서 시작해 더 크면 갱신
- 플래그: `found = False` → 조건 만나면 `True` → 반복 뒤 판단

## 6. 오늘의 함정 모음

| 함정 | 증상 | 예방 |
|---|---|---|
| `range(5)`에 5가 없음 | 마지막 값 누락 | 1~N은 `range(1, n+1)` |
| `count += 1` 빠뜨림 | **무한 루프** | while 3점검 (시작·조건·갱신), Ctrl+C 탈출 |
| `total = 0`이 반복 안 | 매 바퀴 초기화 → 마지막 값만 남음 | 누적 변수·빈 리스트는 반복 밖 |
| 부분 평균을 `len(전체)`로 나눔 | 평균이 작게 나옴 | 조건에 걸린 `count`로 나누기 |
| `temps = temps.sort()` | 리스트가 `None` | 리스트 메서드는 원본을 바꿈 |
| elif 넓은 조건 먼저 | 95점이 "보통" (오류 없음) | 높은 기준부터 위에 |
| 들여쓰기 풀림 | 블록 밖 줄이 항상 실행 | 블록 소속을 항상 의식 |
| `0.1 + 0.2` 형 오차 | `78.80000000000001` | 표시는 `:.1f`, 저장은 `round(값, 1)` |

## 7. 스스로 점검

- [ ] `range(1, n+1)`을 써야 N이 포함되는 이유를 안다
- [ ] 누적 변수를 반복 밖에서 초기화해야 하는 이유를 설명할 수 있다
- [ ] for와 while을 언제 골라 쓰는지 안다
- [ ] 무한 루프의 원인 3가지와 탈출법(Ctrl+C)을 안다
- [ ] break와 continue의 차이를 예로 들 수 있다
- [ ] `for t in temps`와 `for i in range(len(temps))`의 차이를 안다
- [ ] 빈 리스트 + `append` 패턴으로 필터링/가공 리스트를 만들 수 있다
- [ ] 플래그 변수 패턴(False → True → 판단)을 쓸 수 있다
- [ ] `sensors[1][0]` 같은 이중 인덱싱을 읽을 수 있다
